# Mockups

These are the source files of the boards on the TV Home Screen Layouts canvas:
https://claude.ai/artifact/AFHQKmbvmFHXpyJ2fZ4MuC

They are Claude Design canvas files (`.dc.html`) and only render on that canvas, not when you open them
directly in a browser. Open the canvas link to see them working. Here, they're the reference for exact
colors, sizes and layout while building, and they're the same as the canvas as of Nov 4, 2026.

## Main screens: dark mode (the default)

| File | Board |
| --- | --- |
| `HomeNoirCrimsonFrost.dc.html` | Music Home, dark mode, including dark Jazz mode |
| `HomeMore.dc.html` | More: Picks for you and Scores |
| `AllApps.dc.html` | All apps |
| `Art.dc.html` | Art Mode |
