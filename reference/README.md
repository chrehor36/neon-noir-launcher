# Reference

## The TV

- **New (ordered 2026-11-05):** TCL 75" Class QM7L Pro (model 75QM7L Pro), SQD-Mini LED, 4K, Google TV,
  bundled with an Allstate 3-year protection plan (5 years of coverage in total).
  - Panel: 3840x2160, 144 Hz (288 Hz at 1080p in Game Accelerator 288), Dolby Vision.
  - Four HDMI 2.1 ports (the non-Pro QM7L has two), eARC, Ethernet.
  - TSR AI Pro processor, Google TV 14 (Android 14). TCL doesn't publish the RAM.
  - Manual and Quick Start Guide: [TCL support, QM7L Pro series](https://support.tcl.com/en_US/qm7l-pro-series),
    75" row.
- **Earlier plan:** the 85" QM7L Pro (Costco item 9685007).
- **Current:** a Sharp Aquos Quattron, 70" measured corner to corner, with burn-in. Photos are in
  `current-tv/`.
